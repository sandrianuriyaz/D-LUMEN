# Checklist Pengumpulan

1. Jalankan `python scripts/gate.py --workers 2` sampai `GATE OK`.
2. Jalankan eksperimen fisik dan simpan CSV/JSON/event/log/screenshot tanpa mengubah angka.
3. Isi BAB IV dari hasil nyata dan bedakan simulasi dengan node fisik.
4. Jalankan `python scripts/pack_source.py`.
5. Periksa ZIP tidak memuat `.env`, password, `.venv`, cache, atau GeoTIFF besar.
6. Sertakan laporan, video MP4 maksimal lima menit, source ZIP, hasil benchmark, grafik, serta sumber aset.

Bukti minimum: foto 10 perangkat, dashboard sembilan Worker, Task Manager multiprocessing, job lengkap, failure/recovery, tabel E1–E6, grafik, dan keluaran `GATE OK`.
